# Hook Studio 产品宪章 v1.0

状态：执行批准  
日期：2026-07-10  
用户：面向美区 TikTok 的中国跨境电商剪辑师

## 产品目标

交付一个全中文、访问码登录的多模型钩子生成网站。用户用三步完成工作：选择图片或视频模式，选择预设并填写一句产品描述，可选上传参考图，然后生成、预览和下载 9:16 钩子素材。

## v1 功能

- 图片钩子：GPT Image 2，9:16，图片日量不限，独立图片队列和并发。
- 视频钩子：Seedance 2.0，4-5 秒，9:16，要求原生环境音/动作音，独立视频队列和并发。
- 全站视频每日 100 条硬上限，UTC+8 重置；客户码可配置更低子配额。
- 六个首发预设：痛点直击、悬念开场、对比冲击、强视觉开场、真实使用场景、手持动作证明。
- 参考图上传、生成队列、诚实 ETA、画廊、预览、下载、重生成、软删除。
- 三个客户访问码和一个管理码；客户数据互不可见。
- 管理后台：客户用量、配额、启停、全局上限、健康与备份状态。
- SQLite 与 `events.jsonl` 双写；事件与产物索引保留至少 180 天。
- 每日备份 SQLite 和日志到 OSS，保留 30 份；提供恢复命令和演练证据。
- 每周预设下载率重排、10% 模板灰度框架、Hook Insights 与 10 行运维摘要。

## 生成可靠性

视频任务必须经过三个阶段：

1. `preflight`：版本化 skill policy 检查参考槽位、提示词角色、动作因果、时长、比例、禁用元素和原生声音要求。
2. `provider`：记录 submit、poll、retry、provider job ID、延迟、失败原因和队列等待时间；超时最多重试一次。
3. `postflight`：下载或探测成片，检查 9:16、4-5 秒、视频流、音轨、可播放性和产物 URL；未通过不得冒充成功。

v1 的 skill policy 来源：

- `seedance-reference-prompt-gate`
- `video-qc-automation`
- `seedance2_prompt_rules.md`
- `seedance2_audio_prompt_rules.md`
- `storyboard_rules.md`
- `tiktok_ad_ready_checklist.md`

线上服务不依赖本机 Codex 运行时。上述能力蒸馏为仓库内的版本化确定性 policy pack，每次事件记录 policy 名称、版本和检查结果。

## 明确不做

商品 URL 一键流、多语言界面、在线支付、更多模型接入、批量生成、团队协作位。

## 完成标准

- 公网网址可访问，无码 API 返回 401。
- 图片、视频各完成至少三次真实成功生成。
- 视频全站日顶、客户子配额、UTC+8 重置有自动测试。
- 图片和视频队列互不占用并发槽。
- 管理后台可用，事件可导出。
- 备份恢复演练留证。
- Playwright 覆盖登录、两种模式、画廊动作、额度显示和管理后台。
- 交付访问码、管理员码、GitHub 仓库和中文运维手册。
