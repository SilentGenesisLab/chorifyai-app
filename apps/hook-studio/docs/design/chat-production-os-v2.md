# Hook Studio Chat Production OS v2 设计

日期：2026-07-10  
状态：已批准实施  
目标：把现有表单式 Hook Demo 升级为 Codex 式多模态 AI 视频生产工作台，所有可见生产模块都必须真实执行。

## 1. 产品边界

工作台必须支持：

1. 多对话历史、自然语言输入和对话内图片/视频返回。
2. 文本、图片、视频、音频、常见文档和 HTTP/HTTPS 链接解析。
3. 右侧媒体预览、任务阶段、排队数、成功/失败数和批量下载。
4. 左下角账号名、视频额度、图片额度；图片每日上限 1000 张，视频按实际生成分段扣减。
5. 视频生成前追问总时长；支持 60 秒以及更长视频，不限制工作台总时长。
6. 生成前返回可审阅故事板和分镜图，只有确认后才生成视频。
7. 真正可执行的自由创作、参控复刻、批量生产、逆向分析、定向替换和声音替换。
8. 对话、附件、解析、故事板、确认、提示词、任务、产物和行为信号结构化留存与表格导出。
9. 登录页使用有合法来源记录的高质量图片/视频轮播，不把远端短时链接当运行依赖。

不允许：前端直连 provider、假按钮、仅在内存保存任务、未确认故事板就消耗视频额度、把规则 fallback 冒充 AI 分析。

## 2. 交互结构

### 2.1 桌面三栏

- 左栏：新建对话、历史对话、生产工具入口；底部固定账号、图片额度、视频额度和退出。
- 中栏：消息流。用户文本与附件、系统追问、解析结果、故事板、确认操作、排队状态、图片和视频均是消息。
- 右栏：选中媒体的大尺寸预览、当前任务阶段、图片/视频独立队列、等待/执行/成功/失败数量、批量选择和 ZIP 下载。

手机端左栏与右栏改为抽屉，中间消息流和底部输入框保持主视图。

### 2.2 输入器

输入器不提供拍法预设。它提供命令型工具模块：

- 自由创作
- 参控复刻
- 批量生产
- 逆向分析
- 定向替换
- 声音替换

工具只决定执行契约，不替用户填写创意模板。输入器支持多附件、链接、总时长、批次数量和发送。

### 2.3 对话状态机

```text
用户消息
-> 附件/链接解析
-> 意图与缺口判断
-> 缺时长则回问
-> 规划镜头与额度预估
-> 生成故事板/分镜图
-> waiting_storyboard_approval
-> 用户确认或要求修改
-> 分段生成/替换/批量执行
-> 技术 QC
-> 拼接与声音处理
-> 对话内返回成片
```

确认使用版本号；旧版本故事板的确认请求返回 409，避免错烧额度。

## 3. 真实能力路由

### 3.1 自由创作与长视频

总时长可为任意正整数。系统把总时长拆成 4-15 秒镜头，保证每段总和等于用户目标。每段先生成故事板图；确认后并发受控地提交 Seedance，后续镜头使用上一段成片或末帧作为连续性参考，最终调用 Kernel `/capabilities/v1/media/transcode` 拼接。

预计视频额度等于实际 Seedance 分段数乘以批次数量。确认前只预留图片故事板额度，不预留视频额度。

### 3.2 参控复刻

参考视频先经媒体探测和多模态理解，输出结构、节奏、镜头距离、动作链和不可复制项。每个参考都持久化 `controls` 与 `must_not_control`；图片锁人/商品/场景，视频只控制动作或节奏。用户确认复刻故事板后再映射到 Seedance `image_urls`、`video_urls` 和时间轴提示词。

### 3.3 逆向分析

真实执行包括：媒体探测、视频理解、关键帧抽取、语音转写（有语音时）、逐镜头结构、声音/字幕摘要、可迁移结构和禁止复制边界。结果保存为结构化 `reference_analyses` 投影，并在对话内以时间轴表返回。

### 3.4 批量生产

批量任务以一个母计划产生多个 variant。每个 variant 独立拥有故事板、分段、额度、任务状态和成片；批量并发由服务端信号量控制。失败只重试失败 variant，不重烧成功项。右栏支持多选后生成 ZIP。

### 3.5 定向替换

替换场景、商品或人物时，用户必须提供源视频、目标时间段和替换参考。系统只重生成目标镜头：源片作为 `video_urls` 控制镜头与动作，替换图片控制新主体，提示词明确保持项；完成后把目标镜头拼回原视频。整片重生成不能标记为“定向替换”。

### 3.6 声音替换

声音替换不依赖视频模型：从源视频提取/移除原音轨，调用服务端 TTS 生成新音频，按目标区间使用 ffmpeg 混音或替换，再执行音轨和时长 QC。克隆声音只有在权利/授权字段确认后才能使用；默认使用非克隆商业声音。

## 4. 服务边界

- Hook Studio：对话、解析、故事板确认、长任务编排、配额、训练投影和 UI。
- AI Video Kernel：GPT Image、Seedance、媒体探测/抽帧/拼接、OSS、视频理解。
- chorify-ai-service：TTS、ASR 上传、声音资产。
- Workstation crawler：受支持平台公开链接解析；普通网页走受限 HTTP 抽取。
- SQLite：业务事实和任务状态；OSS：二进制资产；`events.jsonl`：追加式审计。

任何密钥只在服务端环境变量或 secret 文件中读取。

## 5. 数据模型

增量新增：

- `schema_migrations`
- `conversations`
- `messages`
- `assets`
- `message_assets`
- `asset_extractions`
- `asset_segments`
- `task_runs`
- `task_jobs`
- `storyboards`
- `storyboard_shots`
- `quota_ledger`
- `activity_events`
- `training_examples`

旧 `jobs/events/daily_usage/settings` 保留。旧 job 幂等回填到“历史生成”对话，不重写旧事件日志。

训练投影必须包含：用户输入、附件摘要、解析证据、工具类型、时长、故事板版本、确认/修改信号、最终提示词、provider 参数、产物、QC、下载/重生/删除行为。管理员可以 CSV 或 JSONL 导出；访问码明文不进入训练导出。

## 6. 安全与配额

- 图片上限：全站每日 1000，客户默认 1000，可由管理员下调。
- 视频上限：沿用全站每日 100 个生成分段，客户子配额服务端强制。
- 额度状态：`reserved -> succeeded|released`，失败释放；故事板图片和最终图片分别记账。
- 链接解析：只允许 HTTP/HTTPS，解析 DNS 与每次重定向，拒绝私网/环回/链路本地地址；限制大小、超时和 MIME。
- 上传：流式落临时文件后上传 OSS；限制扩展名、MIME 和大小；SQLite 不保存二进制。
- 下载：只打包当前客户拥有且已成功的资产。

## 7. 登录轮播

使用三项可本地托管的授权素材：编辑工作台、电影摄影设备、产品摄影场景。素材来源、作者、原始页面和许可类型写入 `assets/login/ATTRIBUTION.md`。视频首帧作为慢网 fallback；轮播尊重 `prefers-reduced-motion`，登录表单始终保持可读对比度。

## 8. 验收

1. 无码 API 401，跨客户读取会话/资产/任务 404。
2. 可新建、切换、删除多对话，刷新后历史仍在。
3. 文本、图片、视频、文档和链接均产生真实解析记录。
4. 无预设也能发起任务；视频缺时长时系统必须回问。
5. 故事板确认前没有视频额度预留；确认后按分段数显示并扣减。
6. 对话内可见故事板、图片和可播放视频；右栏预览与任务数字同步。
7. 60 秒和超过 60 秒计划能正确拆段；真实 smoke 至少完成两段生成和拼接。
8. 复刻、批量、逆向、场景/商品/人物替换和声音替换各有真实执行测试，不能用 mock 证明生产可用。
9. 批量 ZIP 只包含选中且有权限的产物。
10. 管理后台可查看结构化对话/任务表并导出训练 JSONL/CSV。
11. 桌面与手机 Playwright 无重叠、横向溢出或不可达控件。
